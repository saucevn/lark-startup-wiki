# create-lark-startup-wiki

Scaffold a Lark Wiki management repo for your startup.

```bash
npx create-lark-startup-wiki my-team-wiki
```

Interactive prompts (company name, Lark Wiki URL, optional brands) generate a
ready-to-use repo with:

- `CLAUDE.md` — agent rules
- `docs/` — pre-filled company-info templates (Vietnamese)
- `.github/workflows/validate.yml` — CI lint + structure check
- `.env.example`, `.gitignore`, `.markdownlint.json`

See the main repo for full docs: <https://github.com/saucevn/lark-startup-wiki>
