# Examples

This directory is intentionally empty in v1.0 — we don't bundle any company's real Wiki structure to keep the package focused on tooling.

## Want to see real-world usage?

- **Reference instance:** The framework was extracted from a real Vietnamese F&B startup operating its full company OS on Lark Wiki. The instance repo is private.
- **Walkthrough:** See [`docs/installation.md`](../docs/installation.md) for a sample scaffold output and [`docs/migration-from-private.md`](../docs/migration-from-private.md) for an end-to-end migration scenario.

## Want to contribute an example?

If your team uses `lark-startup-wiki` and is willing to share a sanitized snapshot:

1. Create a folder `examples/<your-team-slug>/`
2. Include only:
   - Your customized `CLAUDE.md`
   - Your `docs/02-wiki-architecture.md` (or equivalent)
   - 1-2 example Wiki pages (sanitized)
3. Add a `README.md` explaining your team size, industry, and what you customized
4. Open a PR

We'll feature notable examples in the main README.
